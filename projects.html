Projet 1 — Dashboard Performance Retail (300+ magasins)

↑ Haut

Power BI • KPI • Analyse ventes • Reporting quotidien

BI / Reporting Retail Pilotage performance

Contexte

Suivi quotidien de la performance commerciale d’un réseau national de 300+ magasins. Besoin d’un pilotage clair et homogène pour les équipes métiers (vente / direction / contrôle de gestion).

Problématique

Centraliser les KPI (CA, commandes, trafic, panier moyen, taux de conversion, etc.) et fournir des dashboards lisibles, actionnables et fiables.

Approche

  • Définition des KPI et règles de calcul (alignement métier)
  • Modélisation et consolidation des données (SQL / fichiers)
  • Création de vues Power BI : tendances, comparaison N / N-1, analyses par magasin
  • Mise en place d’un reporting récurrent et industrialisable

Outils

Supabase (DataWarehouse) • VS Code • SQL (PostgreSQL/MySQL) • Excel (TCD/VBA) • Streamlit

Résultat attendu : amélioration de la visibilité des ventes, réduction du temps de reporting, meilleure réactivité des équipes sur les écarts de performance.

Projet 2 — Dashboard Performance Retail

↑ Haut

Python • Streamlit • pandas • Data viz • Retail analytics

Streamlit Python Retail Analyse KPI

🎯 Objectif

Développer une application interactive permettant de piloter la performance commerciale d’un réseau retail, en comparant les succursales et franchises à travers le chiffre d’affaires, le budget, la croissance N/N-1 et les alertes business.

🧠 Travail réalisé

  • Nettoyage et harmonisation de deux sources Excel hétérogènes.
  • Création d’indicateurs de performance : CA N, CA N-1, budget, croissance, réalisation budgétaire.
  • Ajout de filtres dynamiques : date, région, enseigne, type de réseau.
  • Analyse Top/Flop magasins et détection d’alertes business.
  • Déploiement de l’application sur Streamlit Cloud.

📊 Résultat

Le dashboard permet d’identifier rapidement les magasins performants, les zones de sous-performance et les écarts entre objectif budgétaire et performance réelle.
