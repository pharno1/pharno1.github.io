Projet 1 — Dashboard Performance Retail (300+ magasins)

↑ Haut

Contexte

Problématique

Supabase • SQL • Excel • Power BI • Streamlit

Projet 2 — Automatisation API → Cube BI Achats

↑ Haut

FastAPI • Python • ETL • Supabase • Streamlit • Data Warehouse

API REST ETL Python Supabase Cube BI Dashboard Achats

Contexte

Projet inspiré d’un cas réel en environnement retail : automatiser l’intégration des données achats issues d’un fichier métier afin d’alimenter un modèle décisionnel de type Cube BI.

Objectif

Réduire les traitements manuels, fiabiliser les données achats et créer un flux semi-automatisé allant de la source Excel jusqu’au dashboard décisionnel.

Pipeline réalisé

  • Stockage local du fichier source BI Achats
  • Nettoyage et normalisation des données avec Python / pandas
  • Création d’une API REST avec FastAPI
  • Modélisation d’un schéma en étoile : faits + dimensions
  • Chargement des données dans Supabase / PostgreSQL
  • Création d’un dashboard Streamlit connecté au Data Warehouse

Résultat

Le projet permet de suivre les montants d’achats, les fournisseurs clés, les magasins concernés, les familles produits, les marges estimées et la qualité des données.

Architecture

Excel → ETL Python → API FastAPI → Supabase → Cube BI → Streamlit

Valeur métier : transformation d’un fichier Excel achats en flux BI structuré, traçable et exploitable pour le pilotage décisionnel.

Projet 3 — Analyse Python & Dashboard Streamlit Retail

↑ Haut

Python • pandas • Streamlit • Data Cleaning • Retail analytics

Python Streamlit Data Cleaning Analyse KPI

Objectif

Construire une analyse complète et interactive permettant de piloter la performance commerciale d’un réseau retail en comparant les succursales et franchises.

Travail réalisé

  • Nettoyage et harmonisation de deux sources Excel hétérogènes
  • Traitement des dates mixtes et normalisation des colonnes
  • Importation du fichier Excel sur Streamlit
  • Analyse des données via Python permettant de voir les indicateurs
  • Création d’indicateurs : CA N, CA N-1, budget, croissance et réalisation budgétaire
  • Ajout de filtres dynamiques : date, région, enseigne, type de réseau
  • Analyse Top / Flop magasins et détection d’alertes business

Résultat

Le dashboard permet d’identifier rapidement les magasins performants, les zones de sous-performance et les écarts entre objectif budgétaire et performance réelle.
